## 2. 软件验证：假 SDK、无硬件输出（部分通过）

- [x] 软件验证通过：空格、未知键和 Q 触发零指令；PTY 联调确认 Q 正常退出并恢复终端设置。
- [ ] 未验证：真实 SSH 终端输入结束、SIGHUP 和异常断线的端到端停车表现。
- [x] 软件验证通过：运动键有效期为 0.2 秒，过期输出零；重复键只续期，不积累位移命令。
- [ ] 未验证：初始指令为 ±0.1 m/s、±0.2 rad/s，发布频率为 20 Hz。
- [x] 软件验证通过：真机限幅允许倒车，并限制到 ±0.2 m/s、±0.3 rad/s；保留模拟模块原行为。
- [x] 软件验证通过：正常加速度限制生效，故障停车不被错误的正常运动限速流程延迟。
- [x] 软件验证通过：NaN、Inf、不支持轴和非法命令被拒绝并进入停止流程。
- [x] 软件验证通过：单调时钟控制接收超时，0.3 秒无新消息后进入停车；系统时间调整不延长有效期。
- [ ] 未验证：键盘停止发布、输入缓冲积压和连接异常不会导致旧非零命令重新执行。
- [x] 软件验证通过：控制周期异常不补发累计位移，异常反馈和控制权丢失阻止后续运动输出。
- [x] 软件验证通过：退出、异常和重新启用流程不会自动恢复故障前的运动目标。

- [ ] 未验证：SDK 执行线程不被重复 spin；假 SDK 验证调用顺序与资源收尾。

自动化范围：69 项单元测试通过、2 项跳过；真实静止录包的转换联调、假底盘 ROS 联调、键盘 PTY 联调及合成位姿/扫描的地图保存与恢复均有独立报告。合成参数文件带 `test_only`，仅允许 Domain 125，不能作为实测外参。

## 3. 现场遥控与停车（未验证）

前提：前两阶段通过，现场人员监护、活动范围清空、厂商急停及恢复流程可用。故障注入须在可控低速条件下开展；未确认底层停车机制前不直接以进程强制终止试错。

- [ ] 未验证：显式启用后低速前进、倒退、左转和右转与键盘一致，横移始终为零。
- [ ] 未验证：空格停车，记录指令时间、检测时间、物理停止时间和距离。
- [ ] 未验证：停止按键输入后有效期到期停车；初次按住按键的系统重复延迟不会导致持续旧指令。
- [ ] 未验证：SSH 连接中断后由机器人端执行停车，记录是否需要现场急停介入。
- [ ] 未验证：Q、正常程序退出和输入结束均完成停车。
- [ ] 未验证：经过预先确认的流程验证控制程序崩溃后底层停车，记录与正常退出的差异。
- [ ] 未验证：反馈中断、控制权丢失和控制周期异常进入停止状态。
- [ ] 未验证：故障解除后必须显式重新启用，不自行继续运动。
- [ ] 未验证：正常加减速无明显突跳；默认参数经现场检查适用，调整值及依据已记录。

任何意外持续运动、控制权冲突或非底盘关节运动均判为失败，停止后续移动录包并保留证据。尚未建立现场停车时间/距离门槛前，仅记录实测值，不宣称达到安全性能指标。
