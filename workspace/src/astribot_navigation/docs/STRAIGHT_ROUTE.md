# 直线优先，到点后原地转向

ExactGoalLattice 先检查起点原地对准、起终点之间直线通道、终点原地转向。平移和转动分别按最多 1 cm / 0.01 rad 间隔检查地图和带 padding 的机器人轮廓，未知、地图外、致命障碍和中心内切膨胀区不允许直穿。通过后每 2.5 cm 输出直线路径，末点保留用户精确朝向。RPP 既有 use_rotate_to_heading=true、stateful 目标检查负责先对准行进方向，在位置容差 0.15 m 内原地转到最终朝向（0.08 rad 容差）。位置到达仍沿用既有容差，不声称精确零误差。

直线或端点转身空间不足时继续使用现有 lattice 绕障规划；平移目标朝向采用起点到目标的方向，而不是用户最终朝向，并额外检查目标位置到最终朝向的原地旋转。绕障仍可能有曲线，不强迫穿越地图障碍。保留现有平滑、静态地图、膨胀、速度限制和控制器碰撞检查。

测试编译调用生产 straight_route.hpp，覆盖目标朝向不影响直线几何、直线受阻、起点/终点旋转受阻、同位置只转向及跨 ±pi 的最短旋转。相关 Python 回归 35 passed, 1 skipped；硬件 --check 通过。编译导航插件后需用户重启服务加载，未运行真机运动验收。
