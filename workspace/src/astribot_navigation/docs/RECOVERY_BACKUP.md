# 导航失败后的有界回退恢复（2026-10-29）

已授权在预测碰撞、无可行路径/轨迹、完整机身复核失败、控制器无进展后恢复原目标；不对传感器/定位/控制权故障、浏览器断线、用户停止、动作应答超时盲目倒车。没有接触力/保险杠事件输入，不能声称能判断真实碰撞；已接触物体时仍先停车确认。

## 流程

Nav2动作失败 → 保留原目标及浏览器许可 → 向SDK撤回目标超前量 → SDK新鲜反馈确认停稳并额外连续0.3秒 → 检查地图与实时点云 → 最多0.03 m/s直线回退0.15m → 再次确认SDK停稳0.3秒 → 从当前位姿重新发送原目标，重新规划。

每个目标最多2次恢复，短时数据暂停恢复不重置此计数；每次恢复总期限12秒。用户取消/断线立即失效，旧任务不能被迟到指令复活。不自动清除SDK故障或接管丢失控制权。恢复期间每帧继续检查健康和后退空间，任何检查失败均请求位置保持并结束本次目标。

## 回退空间与执行器

静态地图逐厘米检查完整带padding机身扫掠；未知格、地图外拒绝。检查距离=剩余回退距离+0.15m，覆盖现有10cm目标领先预算及额外缓冲。完整新鲜前后投影点云（不是网页600点抽样）经各自源时刻LIO变换到当前底盘，检查扫掠区域。任一源>0.5秒、历史姿态缺失、有效点不足、检测到障碍均拒绝。正常导航仍保持静态地图策略，实时云额外用于回退许可。

普通导航command仍拒绝负速度；仅显式backup_command能给有效任务发送[-0.03,0] m/s、角速度固定0的后退。原SDK反馈、0.3秒指令、0.5秒执行许可、10cm目标领先预算均保留。前进/侧向异常、回退yaw偏差>0.05rad、横向偏差>3cm均停止恢复。SDK本地坐标语义与现有键盘/导航一致。

## 起步复核问题修复

0.65m膨胀未覆盖带padding机身约0.711m外接角半径，Smac中心代价快速判定可能漏检角部，完整复核随后拒绝。默认改0.85m；运行时对自定义配置也保证膨胀覆盖外接半径加一个栅格对角线。不缩小1.0×0.9m碰撞包络、1m规划基元或删除完整复核。27个邻近位姿只规划旧配置6次失败、新配置0次失败。后续闭环替身继续行驶时另有“无有效路径”的情况，不能声称此参数修复保证整条真实路线成功，因此增加上述恢复机制。

## 验证边界

测试覆盖停稳顺序、距离/速度/次数/超时、后方静态及实时障碍、抽样可能遗漏的小点、旧点云、侧偏/反向异常、普通负速度拒绝、取消后不能复活。真实ROS执行器mock后端验证专用倒车指令和取消，Domain125/localhost，无SDK。没有自动发送实际倒车或导航目标；物理制动、后退精度及现场恢复仍需用户验收。
