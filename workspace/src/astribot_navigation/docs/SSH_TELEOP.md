# S1 SSH 键盘遥操

在 S1 上执行，无需编译 ROS 工作区：

```bash
cd /home/astribot/TowerGO/workspace/src/astribot_navigation
./scripts/tg-teleop.sh --dry-run
./scripts/tg-teleop.sh
```

从电脑直接进入：

```bash
ssh -t S1 '/home/astribot/TowerGO/workspace/src/astribot_navigation/scripts/tg-teleop.sh'
```

| 按键 | 功能 |
|---|---|
| W / S | 沿底盘当前朝向前进 / 后退 |
| Q / E | 原地左转（逆时针）/ 右转（顺时针） |
| A / D | 沿底盘当前朝向左横移 / 右横移 |
| R / F | 腰部升高 / 降低，默认 0.02 m/s；松键保持高度目标 |
| H / P | 长按进入初始 / 打包姿态；P 需配置可靠的动作顺序 |
| 空格 | 底盘冻结最后目标；姿态动作调用 SDK 停止 |
| + / - | 同时提高 / 降低速度一档；普通键盘 = 也可加速 |
| X / Ctrl+C | 退出；Q 不是退出键 |

大小写均可。每个方向字符有效 0.2 秒，持续按键重复可续期；松手后不再收到字符则冻结目标。终端不提供真实松键事件，首次长按到开始自动重复之间可能短暂停顿。本版支持单方向前后、横移或转向，不支持组合方向运动或一次按键永久行驶。同批输入停止/退出优先，多个方向只取最后一个，不保存动作队列。未知字符（包括方向箭头）停止积分；请使用表内字母。调速不会延长运动有效期。

默认线速度 0.05 m/s、角速度 0.10 rad/s。前后与横移共用线速度，范围 0.01–1.0 m/s，每档 0.01；角速度范围 0.025–0.25 rad/s，每档 0.025。可指定初值：

```bash
./scripts/tg-teleop.sh --linear-speed 0.03 --angular-speed 0.075
```

## 控制行为

真机入口采用厂商 202 示例的局部累计指令定义：以 100 Hz 固定步长直接积分局部 x、y 和 yaw：W/S 仅改变 x，A/D 仅改变 y，Q/E 仅改变 yaw，不根据 yaw 额外旋转速度。方向键只给底盘发送目标（明确关闭默认躯干目标和 WBC）；H/P 使用同一个 SDK 实例控制上身，R/F 单独控制躯干高度；两者均禁止底盘继续积分。延迟后不补发积压帧；超过 0.1 秒的周期停顿退出。已有 ROS keyboard/chassis 入口与其硬件验证配置不变；本工具的目标保持停车方式不表示已有硬件验证合同已通过。

**停车是冻结最后目标，不是立即刹停。** 底盘可能继续收敛到目标；正常退出后保持约 3 秒再释放控制权。失去控制权则不再发送目标。信号、EOF、异常和输入超时都有处理，但强杀、系统卡死、网络缓冲或 SDK 原生调用阻塞无法由此 Python 工具保证停车。现场物理急停必须可用。

## 长按姿态控制（2026-10-12）

- **H 初始姿态**：同一字符需在至少三次输入中连续自动重复 0.6 秒，每次间隔小于 0.2 秒。首次键盘自动重复前的延迟不计入确认时间；短按或一次粘贴多个 H 不触发。
- **P 打包姿态**：相同长按规则。当前未找到厂商的打包关节参数及动作顺序，默认禁用 P 并显示“未配置”，不使用猜测的角度。
- 进入姿态前停止 SDK 运动并以当前位置重置目标；动作期间不发送底盘目标。H 调用 SDK `move_to_home(duration=5.0, use_wbc=False)`，保留厂商检查及中间姿态逻辑。

### 配置打包动作

取得厂商定义的上身关节目标及有序中间点后，保存为 `config/teleop_pack_pose.json`，原启动命令会自动读取；也可通过 `--pack-pose /绝对路径/文件.json` 指定。配置示意如下，**下列空 steps 不可执行，必须填写真实定义**：

```json
{
  "source": "填写厂商配置文件及版本，或已核验路径的来源",
  "steps": []
}
```

每个 step 只有 `duration` 和 `joints` 两项。`duration` 为 3–30 秒；`joints` 必须包含以下六组，依次按 SDK 关节顺序填写：

| 名称 | 元素数 | 单位 |
|---|---:|---|
| astribot_torso | 4 | rad |
| astribot_arm_left | 7 | rad |
| astribot_gripper_left | 1 | SDK 夹爪数值（0 开、100 闭） |
| astribot_arm_right | 7 | rad |
| astribot_gripper_right | 1 | SDK 夹爪数值（0 开、100 闭） |
| astribot_head | 2 | rad |

允许 1–10 个有序步骤，总时长不超过 120 秒，禁止底盘目标。运行时检查所有步骤的 SDK 关节限位，并在每段运动前使用厂商 `check_to_joint_position` 检查路径（与 Home 相同的 0.03 m 参数）；检查失败则停止退出。此检查不等于感知环境障碍，也不能把单个终点快照当成已核验的完整打包路径。

## R/F 单独调整腰部高度（2026-10-12）

原启动命令即可使用 R 升高、F 降低；连续按住会通过键盘自动重复续期。默认速度 **0.02 m/s（2 cm/s）**，与底盘速度及 `+/-` 独立；可用 `--torso-speed` 指定 0.001–0.02 m/s，例如：

```bash
./scripts/tg-teleop.sh --linear-speed 0.03 --angular-speed 0.05 --torso-speed 0.02
```

每次开始调整时读取 SDK 上一次躯干关节目标，通过只读正解得到目标位姿，保持目标 x/y 和朝向，仅改变 z，通过 SDK 逆解得到四个躯干关节目标；实际反馈用于跟随误差与限幅检查。新按键衔接上一次命令，避免把跟随偏差当成新的命令起点。这里的高度是**底盘坐标系中躯干末端的 z**，不是机器人头顶离地高度。只下发躯干关节指令，关闭 WBC；手臂、头部会随躯干整体升降，并不保持其世界坐标位置。

- 松键约 0.2 秒无新输入、空格、换成底盘方向键或 H/P 后停止增加高度、停止重发腰部目标，SDK 保留最后下发的关节目标；不宣称立即刹停。
- 单次只控制一种运动。R/F 期间底盘不继续积分；H/P 执行或收尾期间 R/F 只请求停止姿态。旧姿态结束并松键后，首次 R/F 解除 SDK 停止，之后重新按 R/F 才升降。
- 腰部使用 SDK `control_way="direct"` 下发已经限步的小目标，避免再叠加在线 filter 延迟；安装版 SDK 隔离测试确认最终仍通过关节接口以 `SetDesiredJointPosition(..., True, 0.01)` 接收目标。底盘仍使用原 filter；未修改全局滤波参数或厂商 SDK。目标速度不等于保证的实测速度，控制周期和跟随限制可能使实际运动更慢。
- 默认每个 100 Hz 周期仅改变 0.2 mm 目标高度，不追赶延误周期；不设置未经验证的固定绝对高度上下限。可达范围由 SDK 逆解和当前关节限位决定。
- 逆解不可达、关节越限、单步关节变化超过 0.003 rad 或 SDK 预测的自碰撞距离小于 3 cm 时，拒绝该步并显示“腰部受限”，可反向尝试。此项不检测外部环境障碍。
- 每个周期对准备发送的下一小步检查超前量：关节误差不超过 0.025 rad、高度误差不超过 1 cm 就立即推进；下一步将超预算时保持当前目标并显示“腰部等待反馈”。不再等待误差降到预算的一半，避免稳定跟随偏差导致长时间卡住；不补发等待期间的位移。等待期间仅在 R/F 输入仍有效时，以控制周期重复发送上次已检查目标，刷新当前目标，不增加目标高度；每次重发同样检查限位、自碰撞、输入有效期与控制权。松键后不再重发腰部目标，保留最后下发的关节目标；不代表立即刹停。
- 等待超时依据“最近一次明显收敛”的时间，持续变好可等待超过 2 秒。比较关节和高度误差各自除以超前预算后的最大值，每下降 0.04 才刷新计时（对应主导关节误差 0.001 rad 或主导高度误差 0.4 mm），小幅抖动、反弹以及非主导误差改善不会单独续期。恢复推进的条件是下一小步满足原超前预算。
- 持续按住 R/F 时，跟随误差连续 2 秒无明显收敛，或实测误差超过原保护限值（关节 0.05 rad / 高度 2 cm），仅暂停腰部并停止发送腰部目标，打印一次误差、目标关节及反馈关节，遥操会话与底盘按键仍可使用。持续按住不会自动重试；松键超过按键有效期、空格或切换动作后，再按 R/F 从 SDK 上一次目标开始。解算超过 0.1 秒不发送该步并退出；输入已过期、收到退出信号或控制权丢失时也不下发计算出的新目标。

可加 `--dry-run` 验证按键及互斥；演练使用模拟腰部，不验证实机可达高度、运动方向、自碰撞模型或停止尾程。用户已反馈实机降低期间触发关节滞后保护；本次 direct 小步发送及默认速度调整尚未实机复测。程序文件更新后需退出旧会话重新启动。
