# AMCL 转向不确定性修复与验证

依据：`docs/AMCL_TURN_COVARIANCE_DIAGNOSIS.md`（本机原件 `/tmp/towergo-amcl-evidence/diagnosis.md`）。本轮只修改源码、编译、隔离验证，没有启动真机导航或发送运动目标。

## 修复

### 运动模型

新增 `towergo::LioPlanarMotionModel`，由真机/录包入口 `session.nav_params` 选择；通用仿真默认模型不变。直接将 LIO 的世界平面位移转换为上一个底盘坐标系的平移，再应用到各粒子；保留真实横向位移与净转角。取消差速模型“先转向位移方向、再转回”的分解，避免厘米级横向抖动导致两次约 80° 的虚构转动。

噪声按真实增量计算：

- 纵向方差 `alpha3 * distance² + alpha4 * yaw²`
- 横向方差 `alpha5 * distance² + alpha4 * yaw²`
- 朝向方差 `alpha1 * yaw² + alpha2 * distance²`

保留 alpha1..5=0.05、粒子数、雷达权重及更新门槛 0.05 m/0.05 rad。不修改输入时间、里程计或输出协方差。这个模型采用独立平面平移/转角误差假设，仍需真实转弯验证，不能理解为已测量机器人准确度。

报告的 0.011995 m / 2.8979° 样本：差速模型注入平移标准差约 0.4512 m、合成角度标准差 25.85°；新模型每平移轴标准差约 0.01162 m、朝向约 0.666°。新增 C++ 测试覆盖坐标旋转、横向/倒车位移、角度跨 ±π、零运动、大位移及 1 cm 两侧的连续性。

### 置信度

新增 `confidence.py`，位置与朝向不再混为一个标量。位置使用 XY 协方差最大特征值（包含互协方差；比旧的最大对角线更完整），限值 0.25 m²；朝向限值仍为 0.25 rad²。保存单轴标准差、位置主轴标准差、朝向标准差和 3×3 平面协方差。非法/非有限/非半正定协方差立即拒绝。

已有有效初始化且传感器、TF、AMCL 更新预期、独立扫描匹配都正常时，单次超限只告警；持续 2 秒才撤销置信度。新初始化没有超限宽限期；扫描匹配不可信或数据失效也不借此放行。恢复需协方差正常并连续获得 2 秒新鲜可信的匹配，使用时间滞回，未提高数值门限。

修正状态文字，区分置信度不足、扫描地图匹配不可用、定位数据/TF 过期。固定警告区域保持不变；页面展示位置/朝向不确定性及静止重评估状态。

### 有界静止重评估

只对正常会话中持续协方差超限、进入 `recovering` 的情况发出 `request_nomotion_update`。必须 SDK 新鲜反馈确认静止、保持动作结束、无任务、无活动租约、无 SDK 故障、有控制权、传感器和扫描时刻 TF 正常、扫描匹配可信、AMCL 已激活。

每轮最多 3 次、间隔至少 1 秒，前一服务请求已结束且收到不同 AMCL 时间戳后才允许下一次。总期限 10 秒；无结果、仍不确定或无法恢复则提示手动选点。不会发布 initialpose、清除执行器故障或恢复导航目标；手动取消阻止重评估。初始化及已有局部搜索仍保留各自的原有事务。

### 持续诊断

新增会话文件 `amcl_diagnostics.jsonl`，每个被接受的 AMCL 更新独立记录全部 36 个协方差元素、标准差、源/接收时间、初始化编号、同源时刻 LIO 位姿及相邻 AMCL 更新的局部平移/转角、执行器和控制指令。原始大容量录包结束不会结束此日志。历史覆盖不足时里程计增量为空，不伪造插值。`navigation.jsonl`、质量日志和 `/api/state` 增加 `localization_confidence`；API 增加 `localization_reassessment`，旧最大协方差字段保留兼容。
