## 失败路径证据

- 固定输出契约：空输出、Markdown 代码围栏、非法 JSON、未知候选、错误候选、额外字段、重复键、错误字段类型及思考文本全部被拒绝。
- 即使 JSON 完整，缺少 EOS 仍被拒绝；横图、竖图、无需缩放和边界尺寸的缩放检查通过。
- 实际模型将生成预算限制为 1 token：输出被判为截断且 JSON 非法，测试通过。
- 实际处理后的输入为 270 tokens，将输入上限设为 1：在生成前被拒绝，测试通过。
- 独立 CPU 测试子进程故意等待，使用同一外部 watchdog 在 0.3 s 超时后终止，退出码 -15；失败记录保存在 `timeout-failure.json`。
- 正常推理默认请求超时 120 s、启动超时 300 s。超时或 CUDA 错误终止该轮并保存部分结果，不自动重试。
